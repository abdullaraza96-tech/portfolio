# Abdulla Raza — Data Analyst Portfolio

A static portfolio website designed for GitHub Pages.

## Files

- `index.html` — page structure/content
- `style.css` — styling and responsive layout
- `script.js` — navigation, reveal effects and dashboard lightbox
- `assets/` — profile image, dashboard screenshots, resume and certificate

## Run locally

Open `index.html` directly, or run a small local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish on GitHub Pages

1. Create/open a GitHub repository (for example `portfolio`).
2. Upload **all files and the `assets` folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)` and save.
6. GitHub will provide the live website URL after deployment.
