# Abdulla Raza — Data Analyst Portfolio

Static portfolio website built for GitHub Pages. No build tools or npm required.

## Files
- `index.html` — content and sections
- `style.css` — dark neon-green data/tech visual system
- `script.js` — navigation, reveal effects, lightbox
- `assets/` — profile image, Power BI screenshots, resume, original certificate, project documentation

## Run locally
Open `index.html` in a browser.

For a local server:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.

## Publish on GitHub Pages
1. Create/open the GitHub repository.
2. Upload **all files and the `assets` folder to the repository root**.
3. Commit to `main`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
